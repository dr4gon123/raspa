# config application classification-rule

Configure application classification rule.

## Syntax

```
config application classification-rule
    Description: Configure application classification rule.
    edit <id>
        set app {integer}
        set category {user}
        set classification <name1>, <name2>, ...
        set stop-at-this-rule [disable|enable]
        set type [app|category]
    next
end
```
